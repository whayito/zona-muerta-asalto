# Zona Muerta: Asalto

Shooter cooperativo de 1 a 4 pilotos (PC y Android).

- **Descargar el juego:** [última versión](https://github.com/whayito/zona-muerta-asalto/releases/latest) — `ZonaMuertaAsalto.apk` (Android) o `ZonaMuertaAsalto.exe` (Windows).
- **Jugar con amigos:** crea una *sala online* y pásales el código de 4 letras. Funciona desde cualquier red.

`servidor/` contiene el servidor puente de las salas online (se despliega en Render con `render.yaml`).
